seedance2.0 @ picker helper 使用说明

这是一个 ComfyUI 辅助节点，用来在 prompt 里输入 @ 时弹出参考图缩略图，点选后自动插入 Seedance2.0 能识别的图片引用文本。

重要边界

这个 helper 不会替代原来的 Seedance2.0 资源节点，也不会自己把图片发送给 Seedance。它只负责写 prompt 文本，例如 （图片1）。真正给 Seedance2.0 读取的参考图，仍然必须接到原来的 Seedance2DResource 或你的原资源节点上。

安装信息

URL:

https://github.com/oyuz/seedance_prompt_picker.git

安装后重启 ComfyUI，并刷新浏览器页面。

节点怎么接

  1. 打开你的 Seedance2.0 工作流。
  2. 添加节点 seedance2.0 @ picker helper。
  3. 把参考图接到原来的 Seedance2.0 资源节点，这是给 Seedance 真正使用的图片。
  4. 把同一批参考图、同样顺序，再接到 seedance2.0 @ picker helper 的 Resources_0、Resources_1、Resources_2 等输入口。
  5. 把 helper 的 prompt 输出接到原 Seedance2DPE 的 prompt 输入。
  6. 之后在 helper 的 prompt 文本框里写提示词。

图片顺序规则

Resources_0

对应 prompt 里的 图片1

Resources_1

对应 prompt 里的 图片2

Resources_2

对应 prompt 里的 图片3

两边顺序必须一致。比如角色图在原 Seedance 资源节点里是第 1 张，那它也要接到 helper 的 Resources_0。

怎么使用 @

  1. 在需要引用图片的位置输入 @。
  2. 弹出缩略图选择器。
  3. 如果弹窗挡住 prompt，可以按住弹窗标题栏拖到旁边。
  4. 点击对应图片。
  5. helper 会插入带括号的引用，例如 （图片1）。

示例

输入：

@角色1@ 走进 @场景1@，手里拿着 @道具1@。

依次选择图片后可能变成：

@角色1（图片1） 走进 @场景1（图片3），手里拿着 @道具1（图片5）。

标题栏 i 按钮

helper 节点标题栏右侧有一个蓝色 i 图标，点击后会在 ComfyUI 内显示简短用法说明。

常见问题

输入 @ 没有弹窗：刷新页面或重启 ComfyUI；确认安装的是最新版本。

弹窗有图，但 Seedance 没按图生成：检查同一张图是否也接到了原 Seedance2.0 资源节点，并且顺序一致。

为什么不是 Seedance 原生缩略图胶囊：独立 helper 拿不到原 Seedance2.0 私有富文本编辑器接口，所以采用稳定的 prompt 文本引用方式。
