ComfyUI custom node

seedance2.0 @ picker helper

在 prompt 里输入 @，弹出已连接参考图的缩略图，点选后插入 Seedance2.0 能读的 （图片1） 引用文本。

安装信息

URL
https://github.com/oyuz/seedance_prompt_picker.git
Commit
以本次发布回复中的 Commit 为准

安装后重启 ComfyUI，并强刷新浏览器页面，避免旧 JS 缓存残留。

先看这个边界

helper 不会替代原 Seedance2.0 资源节点，也不会自己把图片发送给 Seedance。它负责生成 prompt 文本；真正的参考图仍然要接到原来的 Seedance2DResource 或你的原资源节点上。

节点连接方式

1

保持原链路

参考图继续接入原来的 Seedance2.0 资源节点，这是模型真正读取图片的地方。

2

复制一份给 helper

同一批图、同样顺序，再接到 seedance2.0 @ picker helper 的 Resources_0、Resources_1 等输入口。

3

输出 prompt

把 helper 的 prompt 输出接到原 Seedance2DPE 的 prompt 输入。

图片顺序规则

Resources_0 对应 图片1
Resources_1 对应 图片2
Resources_2 对应 图片3
Resources_3 对应 图片4

两边顺序必须一致。比如角色1在原资源节点里是第 1 张，它也要接到 helper 的 Resources_0。

使用方式

1

输入 @

在需要引用图片的位置输入 @。

2

选择缩略图

弹窗可按住标题栏拖动，避免挡住 prompt。

3

插入引用

点选后会插入 （图片1） 这种带括号的引用。

示例

原始 prompt 先输入 @ 
角色1@和角色2@牵着手在花园@里散步，角色1摘下一朵花@送给角色2
选择图片后 Seedance 可读文本 
角色1（图片1）和角色2（图片2）牵着手在花园（图片3）里散步，角色1摘下一朵花（图片4）送给角色2

上面的 图片1、图片2、图片3、图片4 分别对应 helper 的 Resources_0 到 Resources_3，并且要和原 Seedance 资源节点顺序一致。

Information 按钮

helper 节点标题栏右侧有一个蓝色 i 图标。点击后会显示简短用法，其中示例为：例如 角色1@ 后选择图片1，会变成 角色1（图片1）。

常见问题

输入 @ 没有弹窗：重启 ComfyUI 后强刷新页面，确认安装的是最新 commit。

弹窗有图，但 Seedance 没按图生成：检查图片是否也接到了原 Seedance2.0 资源节点，并且顺序一致。

为什么不是 Seedance 原生缩略图胶囊：独立 helper 拿不到原 Seedance2.0 私有富文本编辑器接口，所以采用稳定的 prompt 文本引用方式。
